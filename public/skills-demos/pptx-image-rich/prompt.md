# Image-rich strategy deck

## Prompt

Create a 5-slide image-rich strategy deck for an AI document operations product. Audience: product leadership. Tone: polished, visual, decision-oriented. Include generated visuals where they clarify the workflow.

## Reproduce

```bash
officecli new pptx "Image-rich strategy deck" --prompt-file ./prompt.md --local-preview --no-publish
```
