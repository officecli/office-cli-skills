OfficeCLI External Free Unlimited + Hosted Release Report

Release date: 2026-05-12. Report generated after code commit, CLI release, npm publish, platform deploy, endpoint checks, and production database read-only inspection.

Executive Summary

Released External Mode

External Mode is now free with unlimited generations for document and image workflows. External check returns the free-unlimited message and consume records usage without decrementing external quota.

Released Hosted Mode

Hosted Mode remains credit based. Pricing and checkout surfaces expose hosted credit packs only, while historical external orders remain visible.

Released Growth Credits

New users receive 30 hosted credits, and referral activation grants 20 hosted credits to the inviter. Grant paths use idempotency records.

Released Marketing Site

Homepage, pricing, download, docs quickstart, SEO, and prerender fallback now present External and Hosted as the two primary modes.

Implementation Summary

  • runtime_mode=external is allowed for PPTX, DOCX, XLSX, REPORT, and IMG without free, reward, or paid external quota consumption.
  • External license check returns External mode is free with unlimited generations. and signs a free access commit token.
  • External consume writes usage events only, with zero billed units and zero settled credits.
  • External IMG uses the local generation provider configured through config set-generation; hosted IMG keeps using the hosted image route and hosted credits.
  • /api/pricing now returns hosted credit packs only. /api/app/checkout rejects external packs with external mode is free and no longer sold as a paid pack.
  • Signup and referral hosted credit grants were added through hosted_credit_grants with idempotency keys.
  • User app and admin surfaces were updated to expose hosted credits, growth grants, usage, orders, and referral context.
  • Site copy now leads with: External: free unlimited with your own model endpoint and Hosted: OfficeCLI-managed runtime with hosted credits.
