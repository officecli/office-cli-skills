Platform Assurance

How is data handled?

OfficeCLI operates on a "Zero-Persistence" architecture. Once a document is generated and delivered to your specified output, the raw data is purged from our processing nodes immediately.

Does it support my custom fonts?

Yes. You can upload custom TTF/OTF files to your account or reference them via URL in your styling JSON to ensure perfect brand alignment.

API or CLI?

Both. Our CLI is a wrapper around the core API. Use the CLI for dev workflows and local automation, and the API for production applications.

What about bulk generation?

Our infrastructure is designed for massive parallelization. We support concurrent generation requests with automated queue management.
