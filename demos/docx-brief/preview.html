OfficeCLI Skills customer brief

Local Office generation for agent workflows

Why this skill exists

officecli-skills gives local agents a repeatable way to decide when OfficeCLI should handle PPTX, DOCX, XLSX, report, or standalone image work.

Recommended use

Install the skill beside the OfficeCLI binary, then let the agent check capabilities before it writes any final Office artifact.
